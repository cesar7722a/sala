# Caderno de Exercícios Práticos

Esta directoria contém os exercícios e desafios técnicos de todas as 12 semanas da formação, organizados de forma progressiva do básico ao avançado.

---

## Metodologia dos Exercícios

1. **Tentativa Autónoma:** Cada exercício deve ser resolvido por ti antes de pedires revisão ou sugestões ao mentor.
2. **Sem Soluções Expostas:** Para preservar a aprendizagem activa, as soluções não estão pré-preenchidas. Deves colar a tua solução ou referência aos teus commits no espaço reservado de cada ficheiro.
3. **Critérios de Avaliação:** Cada exercício conta com critérios objectivos para validares se a tua solução cumpre os requisitos de arquitectura, tipagem e funcionamento.
4. **Revisão:** Após implementares, podes submeter a tua solução ao mentor para análise detalhada de código, detecção de falhas e propostas de refactorização.
