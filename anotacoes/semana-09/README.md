# Semana 09: Testes Automatizados (Unitários e de Integração)

## 1. Objectivos da Semana
- Compreender a pirâmide de testes no Backend e a relevância de testes automatizados para refactorizações seguras.
- Configurar um ambiente de testes moderno com Vitest ou Jest integrado com TypeScript.
- Escrever testes unitários isolados para regras de negócio (Services) utilizando Mocks e Stubs para a camada de persistência.
- Escrever testes de integração de ponta a ponta com Supertest, validando o comportamento de rotas, códigos de status e respostas HTTP.
- Definir estratégias para isolamento e limpeza de base de dados em ambiente de teste.

## 2. Conteúdos Previstos
- [ ] Pirâmide de testes: Testes Unitários, de Integração e E2E.
- [ ] Configuração do Vitest / Jest com TypeScript.
- [ ] Mocks, Spies e Stubs em testes unitários.
- [ ] Testes de requisição HTTP sem subir servidor físico usando Supertest.
- [ ] Ambientes isolados para testes de integração (dotenv de teste, base de dados limpa por execução).
- [ ] Relatórios de cobertura de código (Code Coverage) e interpretação de métricas.
